# 安装指南

## 系统要求

- **Windows**: Windows 10 或更高版本
- **macOS**: macOS 10.15 或更高版本
- **Linux**: Ubuntu 18.04 或更高版本

## 下载安装

### Windows

1. 访问官网下载 Windows 安装包
2. 双击安装包，按照提示完成安装
3. 启动 Luneto 应用

### macOS

1. 下载 macOS 版本的应用包
2. 将应用拖拽到 Applications 文件夹
3. 右键点击应用，选择"打开"以启动

### Linux

```bash
# 使用 AppImage
chmod +x Luneto.AppImage
./Luneto.AppImage

# 或使用 DEB 包
sudo dpkg -i luneto.deb
```

## 验证安装

启动应用后，您应该能看到欢迎界面。如果遇到问题，请查看故障排除部分。
